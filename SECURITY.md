# Security

Found a way F2 could be made to do harm? An extension getting past what
it's allowed (a host it didn't list, your files), the extension store's
signed list or an update taken without its signature, a token or password
kept somewhere it shouldn't be, something private sent where it shouldn't
go. Please tell its maker privately first, not in an issue:

- **Report a vulnerability**, under this repo's Security tab (GitHub keeps
  it private between you and the maintainers), or
- **Help › Send Feedback** in F2, which goes to its maker alone.

Say what it is, how to make it happen, and F2's version (F2 › About F2).
Every report gets read. Once it's fixed, it can be made public, crediting
you if you'd like.

Only the latest release gets fixes: F2 updates itself, so that's the one to
try it on.

An extension in the store that does more than it says is the store's:
[getf2/extensions](https://github.com/getf2/extensions/security/policy).
